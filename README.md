# チョコスター帳簿（閲覧用）

チョコットランドのチョコスターを記録している帳簿の、**閲覧用の公開版**です。

- スマホなどから残高・在庫・損益を見るためのものです
- この画面からは**記録できません**。記録はパソコンのローカル版から行います
- データは手元のリポジトリから反映しています。反映が止まっていると古いままです

## 中身

| | |
|---|---|
| `app/` | 帳簿アプリ本体 |
| `data/` | 帳簿のデータ（JSON Lines） |

## 更新のしかた

元のリポジトリで次を実行します。反映からコミット・push まで行います。

```
node ledger/tools/publish-sync.mjs           1回だけ
node ledger/tools/publish-sync.mjs --watch   記録のたびに自動で
```
